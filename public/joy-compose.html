3D Viewer

JOY 3D 模型查看器(切角度 + 换动作)。下方文档说明如何让其他前端页面通过 iframe 调用模型能力。

外部调用方式

<iframe id="joy" src="此页面地址/compose.html"
  width="800" height="600" style="border:none"></iframe>

可用指令

action参数说明
setPosepose: string切换动作(打招呼/坐地看景/走路/伸懒腰…)
setFaceface: string切换表情(微笑/大笑/生气…)
setTransformscale/yaw/pitch/x/y缩放、旋转角度、位置偏移
setBackgroundurl: string设置背景图(URL)
capture—截图,返回 base64 PNG
getState—获取当前状态

调用示例

const joy = document.getElementById('joy').contentWindow;

// 换动作
joy.postMessage({ action: 'setPose', pose: '打招呼' }, '*');

// 调角度和位置
joy.postMessage({ action: 'setTransform', scale: 0.5, yaw: -20, x: 0.2, y: -0.6 }, '*');

// 截图(用于你自己的生图 API)
joy.postMessage({ action: 'capture', id: 'shot1' }, '*');

// 接收返回
window.addEventListener('message', e => {
  if (!e.data?._joy) return;
  console.log(e.data.image); // base64 PNG
});
